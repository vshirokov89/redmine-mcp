# Как пользоваться Redmine-коннектором в Claude

Коннектор подключает ваш Redmine (`https://rm.egspace.ru`) прямо к Claude. Он
работает **во всех клиентах Claude** — веб (claude.ai), десктоп и **мобильное
приложение**, потому что сервер коннектора крутится на Cloudflare, а не на вашем
компьютере.

Адрес коннектора: `https://redmine-mcp.v-shirokov89.workers.dev/mcp`

## Как начать пользоваться

Ничего запускать не нужно — просто пишите запросы обычным языком в любом чате.
Claude сам поймёт, что нужен Redmine, и вызовет нужный инструмент.

Если в конкретном чате коннектор не подхватывается:
- убедитесь, что он включён (иконка коннекторов/инструментов в поле ввода → Redmine отмечен);
- при первом использовании после долгого перерыва может потребоваться повторный вход (Connect) — это нормально.

## Примеры запросов

**Задачи — посмотреть**
- «Покажи мои открытые задачи»
- «Что назначено на меня в проекте CRM?»
- «Открой задачу #125591 полностью, с комментариями»
- «Найди задачи со словом "госключ" в проекте INT»

**Задачи — изменить** (потребуют вашего подтверждения)
- «Заведи задачу в проект backend: не открывается форма входа»
- «Смени статус задачи #125634 на "Закрыта" и поставь 100% готовности»
- «Добавь комментарий к #64564: жду ответ от службы безопасности»

**Учёт времени**
- «Залогируй 1.5 часа на задачу #88569, работал над интеграцией»
- «Сколько времени я списал за эту неделю?»
- «Покажи мои записи времени по проекту CRM за сентябрь»

**Проекты и справочники**
- «Покажи мои проекты в Redmine»
- «Какие есть статусы и трекеры?»
- «Кто я в Redmine?» (инструмент whoami / current_user)

## Что умеет коннектор (14 инструментов)

| Инструмент | Что делает |
|---|---|
| `whoami` | Кто вы (GitHub + Redmine), есть ли доступ |
| `current_user` | Ваш аккаунт Redmine |
| `list_issues` | Поиск задач с фильтрами |
| `get_issue` | Задача целиком (комментарии, вложения, связи) |
| `create_issue` | Создать задачу/подзадачу |
| `update_issue` | Изменить поля и/или добавить комментарий |
| `add_issue_comment` | Добавить комментарий |
| `list_time_entries` | Записи о времени |
| `create_time_entry` | Залогировать часы |
| `list_projects` | Список проектов |
| `list_statuses` | Статусы задач |
| `list_trackers` | Трекеры (типы задач) |
| `list_priorities` | Приоритеты |
| `list_time_entry_activities` | Виды деятельности для учёта времени |

## Разрешения инструментов

В настройках коннектора у каждого инструмента три режима:
- ✓ **Always allow** — выполнять без спроса.
- ✋ **Needs approval** — спрашивать подтверждение (по умолчанию).
- 🚫 **Never** — запретить.

Рекомендуется: инструменты на **чтение** (`list_*`, `get_issue`, `current_user`,
`whoami`) — Always allow; на **запись** (`create_issue`, `update_issue`,
`add_issue_comment`, `create_time_entry`) — Needs approval, чтобы ничего не
менялось в Redmine без вашего «ок».

## Важно знать

- **Режим «только я».** Коннектор ходит в Redmine под одним ключом (вашим).
  Все действия выполняются от вашего имени с вашими правами в Redmine.
- **Доступ закрыт.** Войти в коннектор может только GitHub-аккаунт из списка
  разрешённых (`vshirokov89`). Посторонний, даже зная адрес, ничего не получит.
- **Redmine должен быть доступен из интернета** (сейчас так).

## Обслуживание

- **Код и настройки** — в этом репозитории, папка `cloudflare/`.
- **Секреты** (ключи GitHub OAuth, Redmine, cookie) хранятся как зашифрованные
  **переменные сборки** Workers Builds; в деплой их подставляет `cloudflare/deploy.sh`
  через `wrangler deploy --secrets-file`.
- **Обновить коннектор**: закоммитить изменения в `cloudflare/` и запушить —
  Cloudflare пересоберёт автоматически. Либо в дашборде: Deployments → Retry build.
- **Сменить/отозвать Redmine-ключ**: обновить переменную сборки `REDMINE_API_KEY`
  и пересобрать.

## Если что-то не работает

- **Инструменты не появляются** — проверьте, что коннектор «Connected» в
  Настройках → Connectors; при необходимости нажмите Connect повторно.
- **Ошибка авторизации** — переподключите коннектор (Disconnect → Connect),
  войдите через GitHub заново.
- **Redmine возвращает 403/404** — обычно это ограничение прав в самом Redmine
  для вашей учётной записи, а не ошибка коннектора.
