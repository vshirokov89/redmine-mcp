# Как пользоваться Redmine-коннектором в Claude

Коннектор подключает ваш Redmine (`https://rm.egspace.ru`) прямо к Claude. Он
работает **во всех клиентах Claude** — веб (claude.ai), десктоп и **мобильное
приложение**, потому что сервер коннектора крутится на Cloudflare, а не на вашем
компьютере.

Адрес коннектора: `https://redmine-mcp.v-shirokov89.workers.dev/mcp`

## Как начать пользоваться

Ничего запускать не нужно — просто пишите запросы обычным языком в любом чате.
Claude сам поймёт, что нужен Redmine, и вызовет нужный инструмент.

Если в конкретном чате коннектор не подхватывается:
- убедитесь, что он включён (иконка коннекторов/инструментов в поле ввода → Redmine отмечен);
- при первом использовании после долгого перерыва может потребоваться повторный вход (Connect) — это нормально.

## Примеры запросов

**Задачи — посмотреть**
- «Покажи мои открытые задачи»
- «Что назначено на меня в проекте CRM?»
- «Открой задачу #125591 полностью, с комментариями»
- «Найди задачи со словом "госключ" в проекте INT»
- «Покажи мои сохранённые фильтры» → затем «Запусти сохранённый фильтр 42»
- «Найди задачи, где кастомное поле 5 = "Минцифры"» (фильтр по `cf_x`)

**Задачи — изменить** (потребуют вашего подтверждения)
- «Заведи задачу в проект backend: не открывается форма входа»
- «Создай задачу в CRM и сразу приложи файл по ссылке … под именем scheme.pdf»
- «Смени статус задачи #125634 на "Закрыта" и поставь 100% готовности»
- «Добавь комментарий к #64564: жду ответ от службы безопасности»

**Связи задач**
- «Покажи связи задачи #125591»
- «Сделай так, что #125591 блокирует #88569»
- «Свяжи #125591 и #64564 как related»

**Учёт времени**
- «Залогируй 1.5 часа на задачу #88569, работал над интеграцией»
- «Сколько времени я списал за эту неделю?»
- «Покажи мои записи времени по проекту CRM за сентябрь»

**Вложения**
- «Прикрепи к задаче #125591 файл по ссылке https://… под именем scheme.pdf»
- «Приложи к #88569 текстовый файл note.txt с таким содержимым: …»
- «Покажи содержимое вложения 3459» (для текстовых — вернёт текст, для бинарных — ссылку)
- «Удали вложение 3459» (спросит подтверждение)

**Поиск**
- «Найди по всему Redmine "госключ"»
- «Поищи "отчёт" только в задачах проекта CRM, по заголовкам»

**Проекты и справочники**
- «Покажи мои проекты в Redmine»
- «Какие есть статусы и трекеры?»
- «Кто я в Redmine?» (инструмент whoami / current_user)

**Файлы проекта**
- «Покажи файлы проекта CRM»
- «Загрузи в проекте CRM файл по ссылке https://… под именем release.zip»

**Категории задач**
- «Покажи категории задач проекта CRM»
- «Создай в CRM категорию "Поддержка", исполнитель по умолчанию — пользователь 41»
- «Удали категорию 7, а её задачи перенеси в категорию 3»

## Что умеет коннектор (42 инструмента)

> Полный перечень поддерживаемых методов. Актуализируется при каждом изменении
> функционала коннектора.

| Инструмент | Что делает |
|---|---|
| `whoami` | Кто вы (GitHub + Redmine), есть ли доступ |
| `search` | Полнотекстовый поиск по всему Redmine (задачи, вики, новости, документы…) |
| `current_user` | Ваш аккаунт Redmine |
| `list_issues` | Поиск задач с фильтрами (в т.ч. `query_id`, фильтр по кастомным полям `cf_x`) |
| `get_issue` | Задача целиком (комментарии, вложения, связи) |
| `create_issue` | Создать задачу/подзадачу (вкл. кастомные поля и вложение в один вызов) |
| `update_issue` | Изменить поля и/или добавить комментарий (вкл. кастомные поля) |
| `add_issue_comment` | Добавить комментарий |
| `delete_issue` | Удалить задачу (необратимо, с `confirm`) |
| `add_issue_watcher` / `remove_issue_watcher` | Добавить/убрать наблюдателя |
| `list_issue_relations` | Связи задачи |
| `create_issue_relation` | Связать две задачи (relates, blocks, precedes…) |
| `get_issue_relation` / `delete_issue_relation` | Показать / удалить связь |
| `get_attachment` | Метаданные вложения |
| `download_attachment` | Прочитать содержимое (текст) или получить ссылку на скачивание |
| `attach_file_to_issue` | Прикрепить файл к задаче (источник: URL, base64 или текст) |
| `delete_attachment` | Удалить вложение (необратимо, с `confirm`) |
| `list_time_entries` | Записи о времени |
| `create_time_entry` | Залогировать часы |
| `list_projects` | Список проектов (с `include`) |
| `get_project` | Один проект по id/идентификатору |
| `create_project` | Создать проект (нужны права админа) |
| `update_project` | Изменить проект |
| `archive_project` / `unarchive_project` | Архивировать / вернуть (Redmine 5.0+) |
| `delete_project` | Удалить проект (необратимо, с `confirm`) |
| `list_project_files` | Файлы проекта (модуль «Файлы») |
| `upload_project_file` | Загрузить файл в проект (URL / base64 / текст) |
| `list_issue_categories` / `get_issue_category` | Категории задач проекта / одна категория |
| `create_issue_category` / `update_issue_category` | Создать / изменить категорию |
| `delete_issue_category` | Удалить категорию (с опц. переносом задач) |
| `list_statuses` | Статусы задач (id, name, is_closed) |
| `list_trackers` | Трекеры (типы задач) |
| `list_priorities` | Приоритеты |
| `list_time_entry_activities` | Виды деятельности для учёта времени |
| `list_document_categories` | Категории документов |
| `list_custom_fields` | Определения кастомных полей (нужны права админа) |
| `list_queries` | Сохранённые фильтры (запускаются через `list_issues` c `query_id`) |

## Разрешения инструментов

В настройках коннектора у каждого инструмента три режима:
- ✓ **Always allow** — выполнять без спроса.
- ✋ **Needs approval** — спрашивать подтверждение (по умолчанию).
- 🚫 **Never** — запретить.

Рекомендуется: инструменты на **чтение** (`list_*`, `get_*`, `current_user`,
`whoami`) — Always allow; на **запись** (`create_issue`, `update_issue`,
`add_issue_comment`, `create_time_entry`, `create_project`, `update_project`,
`archive_project`, `unarchive_project`, `attach_file_to_issue`, `upload_project_file`,
`create_issue_relation`, `delete_issue_relation`, `create_issue_category`,
`update_issue_category`, `delete_issue_category`) — Needs approval,
чтобы ничего не менялось в Redmine без вашего «ок». Особо опасные (необратимое удаление) —
**`delete_project`**, **`delete_issue`**, **`delete_attachment`**: держите на Needs approval,
а лучше на **Never**, если не нужны.

## Важно знать

- **Режим «только я».** Коннектор ходит в Redmine под одним ключом (вашим).
  Все действия выполняются от вашего имени с вашими правами в Redmine.
- **Доступ закрыт.** Войти в коннектор может только GitHub-аккаунт из списка
  разрешённых (`vshirokov89`). Посторонний, даже зная адрес, ничего не получит.
- **Redmine должен быть доступен из интернета** (сейчас так).

## Обслуживание

- **Код и настройки** — в этом репозитории, папка `cloudflare/`.
- **Секреты** (ключи GitHub OAuth, Redmine, cookie) хранятся как зашифрованные
  **переменные сборки** Workers Builds; в деплой их подставляет `cloudflare/deploy.sh`
  через `wrangler deploy --secrets-file`.
- **Обновить коннектор**: закоммитить изменения в `cloudflare/` и запушить —
  Cloudflare пересоберёт автоматически. Либо в дашборде: Deployments → Retry build.
- **Сменить/отозвать Redmine-ключ**: обновить переменную сборки `REDMINE_API_KEY`
  и пересобрать.

## Если что-то не работает

- **Инструменты не появляются** — проверьте, что коннектор «Connected» в
  Настройках → Connectors; при необходимости нажмите Connect повторно.
- **Ошибка авторизации** — переподключите коннектор (Disconnect → Connect),
  войдите через GitHub заново.
- **Redmine возвращает 403/404** — обычно это ограничение прав в самом Redmine
  для вашей учётной записи, а не ошибка коннектора.
